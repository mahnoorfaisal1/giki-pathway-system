# GIKI Pathway System 🗺️

An interactive campus navigation system for GIKI, developed as a Data Structures and Algorithms semester project.

## 📌 Overview

The GIKI Pathway System aims to make campus navigation easier by helping students find walking routes between different locations across the GIKI campus.

The system will feature a custom interactive campus map displaying important buildings, hostels, academic blocks, the library, cafeteria, sports facilities, and connecting pathways.

Users will be able to select their starting point and destination, find the shortest available route, and visualize the selected pathway directly on the map.

## ✨ Planned Features

- Custom interactive GIKI campus map
- Clickable buildings and campus landmarks
- Search and select starting and destination locations
- Shortest-path calculation using Dijkstra's algorithm
- BFS and DFS graph traversal
- Animated route visualization
- Walking distance and estimated travel time
- Alternative route suggestions
- Campus location and pathway management

## 🛠️ Technologies

## 📚 Data Structures

The project will implement all seven required data structures:

1. Arrays
2. Stacks
3. Queues
4. Linked Lists
5. Trees
6. Graphs
7. Hash Tables

**Primary Data Structures:** Graphs and Linked Lists, used extensively for campus representation and pathway management.

## ⚙️ Algorithms

- Dijkstra's Shortest Path Algorithm
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Searching and Sorting Algorithms
- Binary Search Tree Operations
- Hash Table Operations

## 📍 Project Scope

The initial implementation will use a predefined map of GIKI with stored campus locations, pathway connections, and distances.

The system will focus on graph-based navigation and shortest-path calculations rather than live GPS tracking.
